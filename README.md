# Fake-News
Deteccion de Fake News

FN: Fake News

Desarrollar un modelo de Inteligencia Artificial que ayude a detectar declaraciones políticas engañosas antes de que se viralicen. Con este desafío, tendrás la oportunidad de entrenar un modelo que analice patrones en discursos políticos y ayude a predecir si una declaración es veraz o falsa.
